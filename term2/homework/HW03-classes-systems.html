👀 Worked example — read this carefully first

Below is a mini combat system — exactly the pattern you'll use in adventure_v1.py. Read every step. The trick is on Step 3: methods that change another instance.

Step 1: Set up the classes
class Character:
    def __init__(self, name, hp, dmg):
        self.name = name
        self.hp = hp
        self.dmg = dmg

Same pattern as before — name, hp, dmg on self. We'll use the same Character for hero and enemy here to keep it short.

Step 2: Method that takes another object
    def attack(self, target):
        target.hp -= self.dmg
        print(f"{self.name} hits {target.name} for {self.dmg}!")

target is another Character instance. Inside the method we change target.hp. This is how one object changes another — the magic of OOP.

Step 3: Make a list of enemies
hero = Character("Ada", 50, 12)
goblins = [Character("Grub", 20, 4),
           Character("Snik", 15, 3),
           Character("Murk", 25, 5)]

goblins is a list of three independent Character instances. Each has its own hp, name, dmg — they don't share.

Step 4: Combat loop
while hero.hp > 0 and goblins:
    target = goblins[0]
    hero.attack(target)
    if target.hp <= 0:
        print(f"{target.name} dies!")
        goblins.pop(0)
    else:
        target.attack(hero)
print("Hero wins!" if hero.hp > 0 else "Hero falls.")

Loop runs while hero is alive AND goblins remain. Hero hits the first goblin. If it dies, remove it. Otherwise it hits back. Clean, short, powerful.

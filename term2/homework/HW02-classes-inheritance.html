📚 1 · Recap — what you should already know

5-minute read. From L04 class. If any card is fuzzy, re-watch the lesson recording or ask in our class chat before continuing.

Parent and child

A child class inherits from a parent: class Hero(Character):. The child gets every attribute and method the parent has, for free.

What does super() do?

super().__init__(...) calls the parent's __init__ first. Use it so you don't have to re-type everything the parent already does.

Overriding

If the child defines a method with the same name as the parent, the child's version wins — that's overriding. Useful when the child needs different behaviour.

Why bother?

DRY = Don't Repeat Yourself. Hero, Goblin, Dragon all need name and hp. Put it in Character once.

Pattern

class Hero(Character):
  def __init__(self, name, hp, weapon):
    super().__init__(name, hp)
    self.weapon = weapon

👀 Worked example — read this carefully first

Below is a complete inheritance example. Read it twice — first the Animal class, then how Dog extends it. The key is what super() does on Step 3.

Step 1: Parent class — defines the shared stuff
class Animal:
    def __init__(self, name, sound):
        self.name = name
        self.sound = sound
    def speak(self):
        print(f"{self.name} says {self.sound}")

Animal has a name, a sound, and one method speak(). Every animal will share these.

Step 2: Child class — inherits and adds more
class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name, "Woof")
        self.breed = breed

Dog(Animal) means "Dog inherits from Animal". The child adds breed. The sound is hard-coded to "Woof" because all dogs woof.

Step 3: What does super() do here?
super().__init__(name, "Woof")

It calls the parent's __init__, which sets self.name = name and self.sound = "Woof". Without this line, a Dog would not have a name or sound attribute.

Step 4: Use it — and notice speak() is inherited for free
rex = Dog("Rex", "Labrador")
rex.speak()      # Rex says Woof
print(rex.breed) # Labrador

Dog never defined speak() — but it works because Dog inherited it from Animal. Inheritance saves you typing.

Step 5: Overriding — child wants a different version
class Puppy(Dog):
    def speak(self):
        print(f"{self.name} says yip!")

bella = Puppy("Bella", "Poodle")
bella.speak()  # Bella says yip!

Puppy inherits from Dog (which inherits from Animal). Puppy overrides speak() — its version replaces the parent's for puppies.

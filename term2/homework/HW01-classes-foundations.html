📚 1 · Recap — what you should already know

5-minute read. From L03 class. If any card is fuzzy, re-watch the lesson recording or ask in our class chat before continuing.

What is a class?

A class is a blueprint. Pet is the blueprint, my_dog = Pet() is the actual built thing (the instance).

What is __init__?

The setup function. Python calls it automatically when you write Pet(...). It puts attributes on the new instance.

What is self?

Inside a method, self means "this particular instance". self.name = this pet's name. Without self., it's just a temporary variable.

Attributes vs methods

Attributes = nouns (self.name, self.hp). Methods = verbs (def attack(self):). Methods act on attributes.

How do I use one?

1) Define class Pet: with __init__ and methods. 2) Create one: p = Pet("Buddy"). 3) Use it: p.bark().

👀 Worked example — read this carefully first

Below is a tiny Pet class. Read it once top-to-bottom, then read each step's explanation. Don't skip — this is the pattern you'll use in every task today.

Step 1: Define the blueprint
class Pet:
    def __init__(self, name, sound):
        self.name = name
        self.sound = sound

class Pet: starts the blueprint. __init__ takes name and sound and stores them on self as attributes.

Step 2: Add a method (a verb)
    def speak(self):
        print(f"{self.name} says {self.sound}!")

speak is a method. It uses self.name and self.sound to print this specific pet's line. Notice self is the first parameter — always.

Step 3: Make an instance
buddy = Pet("Buddy", "Woof")
mittens = Pet("Mittens", "Meow")

Each Pet(...) call runs __init__ and gives you a brand-new instance. buddy and mittens are independent — changing one does not affect the other.

Step 4: Use the method
buddy.speak()    # Buddy says Woof!
mittens.speak()  # Mittens says Meow!

buddy.speak() calls speak with buddy automatically passed in as self. That's why self.name is "Buddy" the first time and "Mittens" the second.

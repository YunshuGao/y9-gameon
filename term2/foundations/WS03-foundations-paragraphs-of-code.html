Part A · Name the pattern

Four MCQs. For each snippet, identify which of the four patterns it uses: sequential, conditional, loop, or store/retrieve. · 12 marks total
Q1 · 3 marks
Which pattern does this snippet use?
x = 5
y = 10
print(x + y)
Q2 · 3 marks
Which pattern does this snippet use?
if score > 50:
    print("Pass")
Q3 · 3 marks
Which pattern does this snippet use?
for i in range(5):
    print("Hi")
Q4 · 3 marks
Which pattern does this snippet use?
name = input("Your name? ")
print("Hi", name)

Part B · Predict the output

Three sequential snippets. Trace top-to-bottom — what does each print? · 9 marks total
Q5 · 3 marks
What does this print?

x = x + 2
print(x)
Q6 · 3 marks
What does this print?

Part C · Fill in the condition

Three conditional code lines. Fill the missing comparison or branch. · 9 marks total
Q8 · 3 marks
Fill the blank so the program prints Win when score is 10 or higher.
score = 10
if score ___ 10:
    print("Win")
Q9 · 3 marks
Fill the blank so the program prints Adult when age is 18 or higher.
age = 17
if age ___ 18:
    print("Adult")
else:
    print("Minor")
Q10 · 3 marks
Fill the blank with the keyword that begins the OTHERWISE branch (when the if test is false).
if temp > 30:
    print("Hot")
___:
    print("Comfortable")

Part D · Build with 3 patterns

One small program that uses sequential, conditional, AND store/retrieve patterns. · 6 marks total
Q11 · 6 marks (self-marked)
Write a Python program that combines THREE patterns: (a) store — ask the user for their test score and store it in a variable, (b) conditional — print 'Pass' if the score is 50 or higher, otherwise print 'Try again', (c) sequential — finish by printing 'Thanks for taking the test'. (4–6 lines.)

Starter to expand:

# starter
score = int(input("Your test score: "))
if ___:
    print("Pass")
else:
    print("Try again")
print("Thanks for taking the test")

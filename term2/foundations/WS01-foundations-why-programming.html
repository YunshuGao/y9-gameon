Part A · Big-picture multiple choice (after the video)

Five questions to check you absorbed the main ideas from the video. If you didn't watch — these will be hard. · 15 marks total

Part B · Read this code (predict-the-output)

Four short Python snippets. Don't run them — work out the answer in your head first, then if you really want, run them to check. · 12 marks total
Q6 · 3 marks
What does this Python program print?

Q7 · 3 marks

Q8 · 3 marks
Which output does Python produce here?

x = 8
x = x + 2
print(x)

Part C · Fill in the blank

Three short fill-ins. Match the spacing exactly — the checker is fussy. · 9 marks total

Part D · Reflect in your own words

Two short writing prompts. Two or three sentences each is plenty. Self-marked. · 6 marks total
Q13 · 3 marks (reflection)
In TWO OR THREE sentences, explain in your own words: what is the difference between being a CONSUMER of technology and being a MAKER of technology? Give one example of each from your own life.
Q14 · 3 marks (reflection)
Write 2–3 sentences answering: what is ONE small thing you'd like to make with Python this term? It doesn't have to be impressive — small is fine.

📹 Watch first — the __init__ method and self, explained slowly

A beginner walkthrough of __init__ and self. These two words are new — let the video introduce them gently.

Attributes = the data an object HAS

An attribute is a piece of data that belongs to an object. A dog HAS a name. A player HAS a score. We store these using a special setup method called __init__.

Meet __init__ (the setup method)

__init__ (that's TWO underscores on each side) runs automatically when you build an object. It's where you set up the starting data:

class Dog: def __init__(self): self.name = "Rex" self.age = 3

Now every Dog you build starts with a name of "Rex" and an age of 3. The data lives ON the object.

What is self?

self means "this particular object". self.name = "Rex" means "THIS dog's name is Rex". You write self as the first thing in the brackets, and before every attribute. It's how the object refers to its own data.

Reading the data back

Once an object has attributes, you read them with a dot:

class Dog: def __init__(self): self.name = "Rex" self.age = 3 my_dog = Dog() print(my_dog.name) # Rex print(my_dog.age) # 3

my_dog.name = "go into my_dog and get its name". The dot means "belonging to".

The pattern to memorise

class Thing: def __init__(self): self.something = a_value # store data ON the object

Three new things today: __init__ (the setup), self (this object), and self.name = ... (storing data). Take them slowly — the exercises repeat them a LOT so they sink in.

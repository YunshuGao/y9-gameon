🤝 Lesson 7 — Objects working together

The idea behind every fight scene: one object's method can reach into ANOTHER object and change it.

📖 These are your STUDY NOTES — read them at your own pace. This is the full explanation with lots of examples. You don't have to memorise it — keep it open in another tab while you do the worksheet. When you're ready to practise, go back to the worksheet.

A method that takes another object

Up to now, a method changed self (its own object). Now a method takes ANOTHER object as a parameter — and changes that one:

✅ One object changes another
class Character:
    def __init__(self, name, health, damage):
        self.name = name
        self.health = health
        self.damage = damage

    def attack(self, target):              # target is ANOTHER character
        target.health -= self.damage       # change the OTHER object
        print(self.name + " hits " + target.name)

hero = Character("Hero", 100, 12)
goblin = Character("Goblin", 30, 4)

hero.attack(goblin)
print(goblin.health)      # 18

Reading hero.attack(goblin) slowly

  • hero is self — the one DOING the attacking.
  • goblin is target — the one being hit.
  • target.health -= self.damage = "lower the goblin's health by the hero's damage".
  • Two different objects, talking to each other through one method. That's a game.

The two objects are different roles

The same method works the other way too — the goblin can attack the hero:

goblin.attack(hero)       # now goblin is self, hero is target
print(hero.health)        # 96  (100 - the goblin's 4 damage)

Whoever is BEFORE the dot is self (the attacker). Whoever is in the BRACKETS is target (the one hit). Same method, swapped roles.

A tiny battle loop

Combine with a while loop: trade blows until someone drops:

while hero.health > 0 and goblin.health > 0:
    hero.attack(goblin)
    if goblin.health > 0:        # only hits back if still alive
        goblin.attack(hero)

if hero.health > 0:
    print("Hero wins!")
else:
    print("Hero falls...")

Every combat game is built on this shape. Once you can write one.attack(other), the rest is detail.

📹 Watch first — methods (functions inside a class)

A gentle look at methods — the actions an object can do. Watch before the exercises.

A method is an ACTION the object can do

A method is just a function that lives INSIDE a class. It's something the object can DO. A dog's method might be bark(). A player's might be jump().

class Dog: def __init__(self, name): self.name = name def bark(self): # a METHOD — an action print(self.name + " says Woof!")

Calling a method

You call a method with a dot and brackets, just like reading an attribute but with () on the end:

class Dog: def __init__(self, name): self.name = name def bark(self): print(self.name + " says Woof!") rex = Dog("Rex") rex.bark() # Rex says Woof!

rex.bark() = "tell rex to do its bark action". The brackets () are how you know it's a method (an action), not an attribute (data).

Methods always start with self

Just like __init__, every method has self as its first parameter. That's how the method can reach the object's own data — self.name inside bark() is THIS dog's name.

def bark(self): # self = this dog print(self.name) # reach this dog's name

Attribute vs Method — the quick test

  • Attribute (data, what it HAS): no brackets. rex.name
  • Method (action, what it DOES): has brackets. rex.bark()
  • If it ends in () it's an action. If it doesn't, it's data.

Methods can take extra inputs too

class Dog: def __init__(self, name): self.name = name def greet(self, person): # extra input: person print(self.name + " greets " + person) rex = Dog("Rex") rex.greet("Ada") # Rex greets Ada

After self, a method can have more parameters — just like __init__. rex.greet("Ada") sends "Ada" in as person.

📚 Classes Step-by-Step

Classes are the big idea for Term 3 — so let's learn them slowly and properly, from zero. These 8 lessons each teach ONE small piece of how classes work, with lots of practice. No rushing. If you can finish the Must Do tier of each lesson, you'll walk into Term 3 ready to build a whole game out of classes. Take them in order, one per lesson.
📘

Lesson 1 — What is a class?

Lesson 1 · 50 min · /32 marks

Next term we build a whole game out of classes. Today we start at the very beginning — no rush, no pressure. By the end of this lesson you'll be able to write a class and build an object from it. That's it. One small win.
🏷️

Lesson 2 — Attributes: giving your object data

Lesson 2 · 55 min · /41 marks

Last lesson your objects were empty. A real game dog needs a name; a player needs a score. Today you learn to store data ON an object. This is the half of classes that holds INFORMATION.
🎚️

Lesson 3 — Objects that are DIFFERENT

Lesson 3 · 55 min · /42 marks

In Lesson 2, every Dog was named "Rex". Boring! Real games need a goblin AND an orc, a player called Ada AND one called Sam. Today you pass values IN when you build an object, so each one is unique.
⚙️

Lesson 4 — Methods: teaching your object to DO things

Lesson 4 · 55 min · /40 marks

So far your objects just hold data — they sit there. A real game dog can BARK. A player can JUMP. Today you give objects ACTIONS, called methods. This is the other half of classes: behaviour.
🔄

Lesson 5 — Methods that CHANGE the object's data

Lesson 5 · 60 min · /43 marks

This is where classes become magic. A method can CHANGE the object's data — self.score += 1 — and the object keeps the new value forever. This is how every game tracks health, score, coins, and lives.
👥

Lesson 6 — Many objects from one class

Lesson 6 · 60 min · /40 marks

Here's why games LOVE classes. Write one Enemy class, then build a list of 10 enemies and loop over them all. This is how the Pac-Man game in our class made 4 ghosts, and how every game with 'lots of things' works.
🤝

Lesson 7 — Objects working together

Lesson 7 · 60 min · /40 marks

So far a method changed its OWN object. Today the leap: hero.attack(goblin) — the hero's method reaches into the goblin and lowers ITS health. Once two objects can affect each other, you can build any interactive game.
🏗️

Lesson 8 — Build your own class (capstone)

Lesson 8 · 70 min · /41 marks

You've met blueprints, attributes, __init__, methods, changing data, lists of objects, and objects interacting. Today you put it all together by building ONE complete class from scratch — guided every step of the way. This is your warm-up for the full game you'll build with classes in Term 3.
How the tiers work: every worksheet has ✅ Must do (everyone), ⭐ Should do (most of you), and 🚀 Could do (stretch — often using your own game). Finish Must-do, then climb. Counts as classwork.

📹 Watch first — Classes & Objects, the simplest explanation

A gentle 5-minute intro to what a class is and why we use one. Watch the whole thing before the exercises.

A class is a COOKIE CUTTER 🍪

Imagine a cookie cutter shaped like a star. The cutter is not a cookie — it's the SHAPE that makes cookies. You can stamp out as many star cookies as you like from one cutter.

In Python: the class is the cookie cutter (the blueprint). An object is one cookie you stamp out from it.

The smallest class you can write

class Dog: pass

That's a complete class! class Dog: names the blueprint. pass just means "nothing inside yet". You've made a cookie cutter called Dog.

Building an object (stamping a cookie)

To build an actual dog from the blueprint, you call the class like a function — with round brackets:

class Dog: pass my_dog = Dog() # build one dog your_dog = Dog() # build another dog

Dog() stamps out a new dog object. my_dog and your_dog are two separate dogs, both made from the same Dog blueprint.

The two words to remember today

  • Class = the blueprint / cookie cutter. You write it once. Starts with class.
  • Object = a thing built from the blueprint. You can build many. Made with Dog().

That's the whole lesson. Don't worry about what goes INSIDE the class yet — that's Lesson 2. Today: just blueprint, and building objects from it.

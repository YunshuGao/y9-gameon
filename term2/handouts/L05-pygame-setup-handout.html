🐛 Part C — Common errors & their fixes

10 marks · 4 questions · read the error guide first, then answer.

Most install problems show up as one of the four error messages below. Use this section as your reference any time Pygame breaks. Read it BEFORE asking Ms Gao for help — half the time you'll find the answer here.

Error 1: ModuleNotFoundError: No module named 'pygame'

What it means: Python can't find the pygame package on your laptop. Either pygame wasn't installed, OR it was installed for a different Python.

Fix: Run pip install pygame in the same terminal where you'll run your code. If you have multiple Pythons, try python -m pip install pygame instead — this guarantees it installs for the Python you're actually using.

Error 2: 'pip' is not recognized as an internal or external command

What it means: Windows can't find pip in your PATH. This usually means Python was installed but the "Add to PATH" tickbox was not selected during install.

Fix: Use python -m pip install pygame instead of plain pip install pygame. The python -m prefix routes the request through Python directly, bypassing the PATH issue.

Error 3: error: externally-managed-environment

What it means: You're on a newer macOS or Linux system that protects the system Python. Pygame is refusing to install globally.

Fix: Add --break-system-packages on the school laptop (we have admin permission), OR create a virtual environment (Ms Gao will show you in class).

Error 4: Window opens but immediately closes

What it means: Your code doesn't have a while True: loop, OR the loop has nothing in it that keeps Python waiting. Without the loop, the program exits the moment it opens the window.

Fix: Check that the while True: block is present AND that pygame.display.flip() is inside it. If still broken, show Ms Gao your full code.

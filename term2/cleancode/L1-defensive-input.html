The crash that hit almost everyone

Here's a real number-guessing game from our class (name removed). Looks fine, right?

❌ A real game from our class
guess = int(input("Guess a number 1-100: ")) if guess == secret: print("You win!")

Now type hello instead of a number. Python tries int("hello") and the whole program dies with ValueError: invalid literal for int(). Game over — not because the player lost, but because your code wasn't ready.

Fix 1 — check before you convert (.isdigit())

One student in our class did this perfectly. Before turning text into a number, they CHECK that it only contains digits:

✅ Student A's fix — check first
text = input("Guess a number 1-100: ") if not text.isdigit(): print("Please type a whole number.") else: guess = int(text) # ... rest of the game

Fix 2 — try it, and catch the error (try / except)

Another student used the professional way. try the risky line; if it blows up, except catches it instead of crashing:

✅ Student B's fix — try / except
try: guess = int(input("Guess a number 1-100: ")) except ValueError: print("That wasn't a number — try again.")

Both are correct. .isdigit() is simplest for whole numbers. try/except is the grown-up tool that works for ANY risky line (decimals, file loading, etc.).

The bulletproof pattern — keep asking until it's valid

The best programs wrap the check in a while True loop, so a bad answer just asks again instead of crashing OR continuing with junk:

while True: text = input("Guess a number 1-100: ") if text.isdigit(): guess = int(text) break # good input — leave the loop print("Whole numbers only, please.")
